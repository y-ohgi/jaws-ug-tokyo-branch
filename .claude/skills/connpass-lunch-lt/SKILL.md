# ランチタイムLT会の connpass ページ

## 手本

手本は `connpass/lunch-lt/template/` にある。前回のページをブラウザで見に行かなくても、ここから作れる。

| ファイル | 使う場面 |
|---|---|
| `description-normal.html` | 通常回の説明欄 |
| `description-collab.html` | 支部コラボ会（他支部のゲストを招く回）の説明欄 |
| `info.html` | 「参加者への情報」欄 |

`（ ）` で囲んだ所と `TBD` が、回ごとに埋める所。
運営メンバー紹介とルール/マナーは全回共通なので、そのまま使う。

ただし、connpass 上の最新のページのほうが新しいことがある（メンバーの紹介文が変わった、など）。
既存の回を直すときは、編集画面にある今の説明欄を正として直す。
雛形と食い違っていたら、雛形も同じ変更で直す。

## 説明欄の組み立て

上から、冒頭の一文 → （コラボ会だけ）支部コラボ会の説明とゲスト紹介 → アジェンダ → テーマとアーカイブ → 運営メンバー紹介 → ルール/マナー の順に、白い紙を縦に並べてある。
節の見出しは、紙の上端に敷いた淡いオレンジの帯。

アジェンダは1枠が次の1行。枠を足すときはこの行を複製し、時刻・タイトル・登壇者を書き換える。

```html
<div class="row g-0" style="margin:0;padding:10px 0;border-bottom:1px solid #f1e8d2"><div class="col-3 col-md-2" style="padding:0"><div style="font-size:clamp(16px,4.2vw,19px);font-weight:900;color:#1c1a17;margin:0">12:05</div><div style="font-size:11px;color:#6f6a61;margin:-0.3em 0 0">〜12:15</div></div><div class="col-9 col-md-10" style="padding:0"><span style="font-size:15px;font-weight:900;color:#1c1a17">（LTタイトル）</span><br><span style="font-size:12px;color:#6f6a61">（登壇者名） / （所属）</span></div></div>
```

- 枠を足したら、後ろの枠の時刻もずらす。LT は10分枠、ゲストは15分枠が基本
- 未定の枠は、タイトルを `LT　TBD`（灰色の文字）にし、登壇者の行を消す（雛形の TBD の行がその形）
- 登壇者は「名前 / 所属」。所属が無い人は名前だけ。敬称は付けない

## 見た目の決まり

- イベント名・日時・会場は connpass の画面が出すので、説明欄に書き直さない
- 説明欄は白地。ページ背景のオレンジと同じ色にしない
- 飾りを足さない（英字の小見出し、色つきの札、左に色線を引いた囲み、中央寄せの連続）。使うのは大きな文字・余白・細い罫線・1色の差し色まで
- 余白は `clamp()` で画面幅に連動させてある。数値をいじったら PC とスマホ幅の両方で見る

## connpass の癖

- HTML のかたまりの中に空行を入れない。Markdown として割り込まれて崩れる。雛形は1行につないである
- `style` で効くのは、色・背景色・枠線・余白・文字の大きさ・太さ・寄せくらい。`border-radius`・`display`・`width`・`line-height`・グラデーション・`<style>` は消される
- 横並びは Bootstrap の class（`row` `g-0` `col-3` `col-md-12`）で組める
- 「参加者への情報」欄は 1010 字まで。超えると保存できない
- 「参加者への情報」の保存ボタンは、JavaScript の `click()` では保存されない。本物のクリックで押す
- 保存すると、絵文字が `:television:` のような短縮コードに置き換わる（表示は絵文字のまま）

## 反映

1. connpass の編集画面で説明欄をクリックし、中身を全部入れ替えて保存する
2. 公開中のページを直すときは、保存の前に、変更点を頼んだ人へ見せて確かめる
3. 保存したら、公開ページ（未公開なら preview）を PC 幅とスマホ幅で見て、崩れていないか確かめる

## このリポジトリは公開されている

参加者だけに見せる情報（YouTube の配信URL・アンケートのURL）と、公開前の回の中身（ゲスト・登壇者）は、このリポジトリに書かない。
雛形を直すときも、伏せ字のままにする。
