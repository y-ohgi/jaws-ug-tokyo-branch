```md
## 森ヒルズへのアクセス

南北線 **六本木一丁目駅** もしくは日比谷線 **神谷町駅** から森ヒルズへ地下直結でアクセス可能です。  

### 六本木一丁目駅
南北線六本木一丁目駅からのアクセス方法です。

1: 六本木一丁目駅の南改札より出て進みます。
<img src="https://github.com/y-ohgi/jaws-ug-tokyo-branch/blob/main/imgs/morihills_route/00_route.jpeg?raw=true" width="500" />

2: 直進し、案内看板の「森JPタワー」方面へ進みます。
<img src="https://github.com/y-ohgi/jaws-ug-tokyo-branch/blob/main/imgs/morihills_route/01_route.jpeg?raw=true" width="500" />

3: 分岐点がございますので、右方向へ進んでください（案内看板の「森JPタワー」方面）。
<img src="https://github.com/y-ohgi/jaws-ug-tokyo-branch/blob/main/imgs/morihills_route/02_route.jpeg?raw=true" width="500" />

4: エスカレーターで1階まで上がり、「オフィス受付」の案内に従って森ヒルズへお進みください。
<img src="https://github.com/y-ohgi/jaws-ug-tokyo-branch/blob/main/imgs/morihills_route/03_route.jpeg?raw=true" width="500" />

5: エレベーターホールより34階へお越しください。
<img src="https://github.com/y-ohgi/jaws-ug-tokyo-branch/blob/main/imgs/morihills_route/04_route.jpeg?raw=true" width="500" />
```
