# 無料の ChatGPT などで作るとき

コーディングエージェントやブラウザを操作できる AI が無くても、チャットの AI（無料の ChatGPT・Gemini・Claude など）で作れます。
AI が HTML を書き、あなたがそれを connpass に貼ります。

## 手順

1. 下の「プロンプト」をコピーし、`【ここに頼みたいこと】` を書き換えて、チャットに貼る
2. 続けて、手本の HTML を貼る
   - 新しい回を作るとき：[template/description-normal.html](./template/description-normal.html)（通常回）か [template/description-collab.html](./template/description-collab.html)（支部コラボ会）
   - 今の回を直すとき：connpass の編集画面で説明欄をクリックし、中身を全部コピーしたもの
   - GitHub でファイルを開き、右上の「Copy raw file」ボタンで全文をコピーできます
3. AI が返した HTML を全部コピーし、connpass の編集画面で説明欄の中身と入れ替えて保存する
4. 公開ページをスマホでも開き、崩れていないか見る

参加者への情報欄も同じ手順です。手本は [template/info.html](./template/info.html) を使います。

## プロンプト

```text
JAWS-UG東京 ランチタイムLT会の connpass の説明欄を作っています。
このあと貼る HTML が今の説明欄です。次の変更だけを入れて、HTML の全文を返してください。

【ここに頼みたいこと】
（例：12:25〜12:35 の枠を、ますのさんの「◯◯」に差し替えて）
（例：LT 枠を1つ足して。12:45〜12:55、TBD で。クロージングを 12:55〜13:00 にずらして）

守ってほしいこと：
- 変更する所以外は、1文字も変えない
- 見た目（色・余白・文字の大きさ・class）は変えない。飾りを足さない
- HTML の中に空行を入れない（connpass で崩れる）
- アジェンダの枠を足すときは、既存の枠の行を複製して時刻・タイトル・登壇者だけ書き換える
- （ ）で囲んだ伏せ字が残っていたら、聞いてから埋める
- 返すのは HTML の全文だけ。説明はいらない
```

## うまくいかないとき

- AI が HTML の途中で止まった：「続きを出して」と頼み、つなげてから貼る。それでも長すぎるなら、アジェンダの部分だけを貼って直してもらい、そこだけ入れ替える
- 保存したら崩れた：HTML に空行が入っていないか見る。貼る前に、元の説明欄の中身をメモ帳などに控えておくと戻せます
- 「参加者への情報」が保存できない：1010 字を超えています。AI に「1010字以内に収めて」と頼む
