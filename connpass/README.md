# connpass ページの作り方・直し方

スキルもスクリプトも要りません。**前回の connpass ページが、そのまま設計書です。**
エージェントに前回の URL を渡して、人に頼むのと同じ言葉で頼んでください。

## 前提はこの2つだけ

- エージェントがブラウザを操作できること（Claude in Chrome など）
- そのブラウザで connpass にログインしていること（東京支部の運営は全員、グループの管理者になっています）

管理者なら、前回のイベントの編集画面から説明欄の HTML をそのまま読めます。
エージェントはそれを手本に、見た目をそろえて書けます。

## 頼み方の例

> https://jawsug.connpass.com/event/407659/ の3本目のLTを、ますのさんの「◯◯」に差し替えて

> https://connpass.com/event/406735/edit/ にLT枠を1つ足して。12:50〜13:00、登壇者はTBDで

> 次のランチタイムLT会 #43 のページを、#42（ https://jawsug.connpass.com/event/406735/ ）と同じ見た目で作って。通常回でLTは4本

## エージェントがつまずきやすい所

うまくいかないときは、この節をそのままエージェントに貼ってください。

- 説明欄の HTML のかたまりの中に空行を入れない（Markdown として割り込まれて崩れる）
- 「参加者への情報」欄は 1010 字まで。超えると保存できない
- 「参加者への情報」の保存ボタンは、JavaScript の `click()` では保存されない。本物のクリックで押す
- 公開中のページは、保存する前に変更点を頼んだ人へ見せて確かめる
